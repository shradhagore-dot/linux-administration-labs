# Lab 07 — Storage and Memory

## Objective
Check filesystem space, directory sizes, memory, and block devices.

## Commands
```bash
df -h
du -sh "$HOME"
free -h
lsblk
```

## Check your understanding
1. What is the difference between `df` and `du`?
2. Which command reports memory usage?
3. Why should disk space be monitored on servers?
